# Quy trình kiểm thử theme Shopify (branch atlas_test)

1. Sau khi hoàn thành chỉnh sửa code:
   - Commit thay đổi vào branch `atlas_test`.
   - Push branch `atlas_test` lên GitHub.

2. Deploy theme lên Shopify:
   - Sử dụng lệnh: `shopify theme push --theme atlas_test` để deploy theme mới nhất lên cửa hàng.

3. Kiểm tra giao diện và chức năng trên cửa hàng Shopify.

> Luôn thực hiện đầy đủ các bước trên mỗi lần cần kiểm thử theme!
